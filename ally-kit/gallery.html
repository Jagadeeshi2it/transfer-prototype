Ally Prototype Kit

These HTML/CSS components are built from the AllyGPO Design System library components used in the Transfer Figma file. Sizes, colours and text styles come from Figma, and the class names follow the Figma component names.

The yellow notes under each component list where the Transfer prototype differed from Figma. The kit follows Figma in every case. Open "HTML" to copy a snippet.

Colours

Figma variables · --ak-* custom properties
    Prototype vs Figma
  • The prototype's body text was #21252b. The kit uses #25282a, Figma's text/default.
  • The prototype used near-duplicate greys: #e9ecf1, #eef1f5 and #e3e7ed for borders, and #6b7480 and #6b7280 for labels. The kit uses #dadee3 for table borders, #e0e0e0 for dividers and #64748b for labels.
  • Primary hover was #073f73 in the prototype. Figma uses #173a63 for hover and #122e50 for pressed.
  • The modal overlay was rgba(14,36,63,.45). Figma uses rgba(26,31,38,.40).

    Prototype vs Figma
  • The prototype pages used the system font stack. The kit loads Inter, the font of the design system.
  • The prototype used several sizes the design system doesn't have: 13, 15, 20, 22 and 32px. Map them to the nearest style: 13 → Small 14, 15 → Body 16, 20/22 → H3 24, 32 → H2 28.

Button · Standard (36)

Figma Button · set cbcfe08a… · Type × State × Severity
    Prototype vs Figma
  • Prototype buttons were 40px tall with 0 20px padding, 14px Medium and 0.3px letter-spacing. Figma's Standard button is 36px, padding 8/12, 14px Semi Bold, with no letter-spacing.
  • The prototype's disabled buttons were grey (#f3f5f7 background, #bcc3cd text). Figma's disabled buttons are brand blue at 60% opacity.
  • The prototype set uppercase in CSS. Figma has no transform; the Transfer screens type labels in capitals ("RESET", "SEARCH"). Write the label the way it should read.

    Prototype vs Figma
    
  • Prototype cells had 14/16 padding, headers were 13px Semi Bold on #f8fafc, and borders were #e9ecf1 / #eef1f5. Figma cells have 8px padding; the kit uses 16px (--ak-cell-pad, a deliberate choice for the prototypes; raise it with design so Figma matches), headers are 14px Medium on #f5f7fa, and borders are #dadee3. Every line is 14/20.
    • 
    
  • Figma has no column dividers. Every table, page or panel, sits in a 1px #dadee3 frame with radius 4, and the last row has no bottom line. Inside an ak-box or a card, use ak-table--flush (applied automatically) so the border isn't doubled.
    • 
    
  • Secondary lines (inventory type, station, generic name) are 14px italic #757575 with no top margin. The prototype used 13px #6b7280 with 2px margin in some tables.
    • 
    
  • The prototype's sort icon was a 12px custom glyph with an "A-Z" label. Figma's is the 20px sort-alt icon.
    • 
    
  • Prototype checkboxes were 20px with radius 4. The kit uses a 16px checkbox. Not verified against Figma; check it against the library Checkbox before relying on it.
    • 
    
  • Row hover and selected colours are prototype values (#f8fafc / #eef4fa). Figma doesn't define them.

    When to use
    
  • ak-check: for div-based selectable rows that need a "partly selected" (mixed) state, which a native checkbox can't show from markup.
    • 
    
  • ak-btn--guarded: the button looks disabled but still takes a click, so the click can say why (for example "Select a product card first"). Keep the guard in the handler.
    • 
    
  • ak-btn--icon: a square 48px icon button that sits next to 48px inputs. Add --sm for 36px.
    • 
    
  • ak-select--set: a dropdown with a chosen value shows a brand border, as in the serial status column.
    • 
    
  • ak-sort: header sort label; --on marks the active column and --desc flips the icon.
